# Berichthefte_WPF

## 📌 Overview

**Berichthefte_WPF** is a desktop application developed in **C# using WPF** that allows apprentices to create and export **training reports (Berichtshefte)** as **PDF files** following the official format recommended by the **German Chamber of Industry and Commerce (IHK)**.

The application simplifies the creation of training reports while ensuring they are ready to print and comply with the IHK guidelines.

---

## ✨ Features

- Create training reports (Berichtshefte)
- Enter daily work activities
- Generate reports automatically
- Export reports to PDF
- PDF layout based on the official IHK recommendation
- Simple and user-friendly WPF interface

---

## 🛠 Technologies

- C#
- WPF (.NET)
- XAML
- .NET
- Visual Studio 2022

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/AnassAfathi/Berichthefte_WPF.git
```

### Open the solution

```
Berichthefte_WPF.slnx
```

### Build and Run

Open the solution with **Visual Studio 2022** and press **F5** to start the application.

---

## 📄 PDF Export

The application generates printable PDF training reports that follow the layout recommended by the **IHK (Industrie- und Handelskammer)**.
